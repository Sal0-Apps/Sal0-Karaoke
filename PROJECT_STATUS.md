# Status do projeto

## Versão final

Este repositório representa a versão final publicada do Sal0 Karaokê. O desenvolvimento ativo foi encerrado.

O código e a documentação permanecem disponíveis para consulta, uso, estudo e criação de forks. Pull requests e solicitações de novas funcionalidades provavelmente não serão revisados. Correções de segurança poderão ser avaliadas eventualmente, conforme disponibilidade e prioridade.

Não há garantia de novas funcionalidades, respostas rápidas, suporte contínuo ou compatibilidade com mudanças futuras em sistemas operacionais, serviços externos, modelos de IA, bibliotecas ou plataformas de distribuição.

## Continuidade independente

Qualquer pessoa interessada em continuar o desenvolvimento é incentivada a criar um fork, definir sua própria política de manutenção e documentar claramente as mudanças realizadas. Um fork pode adaptar o software a novos requisitos sem depender de uma continuidade deste repositório.

Para questões de segurança, consulte [SECURITY.md](SECURITY.md). Para informações sobre dados e integrações externas, consulte [PRIVACY.md](PRIVACY.md).
